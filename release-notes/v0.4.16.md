<h3 id="cn-v0416">DSH Notify 0.4.16</h3>

跟进 DSH `0.2.2-rc.5`，通知、提示音与交互行为保持不变。

兼容 DeepSeek Harness `0.2.2-rc.5`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### ⚠️ 调整

- 补充 `0.2.2-rc.5` 的兼容性声明，保留此前每一个已实测版本。这是第一个进入 npm `latest` 渠道的 RC。
- 读取新增的 `docs/upgrade-guide/v0.2.2-rc.4`——唯一覆盖 `rc.4` → `rc.5` 的破坏性变更清单。它只有一项，属于搜索提供方默认值调整：交付的基础组合不再固定 `web.searchProvider`，改由 `dsh-web` 按模型路由选择。本插件不做网页搜索、也不读取任何搜索配置，因此不受影响。
- 对插件绑定的 15 个包做了 `rc.4` → `rc.5` 的逐字节比对。六个决定接口的包除自身版本号外逐字节相同：`dsh-client-ui-slots`（整个 `slots` 服务）、`dsh-host-webserver`（`register(route)`）、`dsh-jobs`、`dsh-client-ui-renderer`、`dsh-client-ui-session`、`dsh-client-connection`。有改动的四个文件要么属于同一次搜索提供方调整、要么是发布元数据：`dsh-base` 的 `cordis.patch.yml` 删掉了固定的 `searchProvider`；`dsh-api-remotes` 客户端只差一个字符（`line:152` → `line:174`，网页设置 schema 里的源码位置标注）；`dsh-client-ui-settings-general` 客户端只替换了界面显示的宿主版本号；`dsh-client-modules` 宿主半边只改了上报的提交号（`70005a5` → `3f85d88`）。两个挂载点的 `.d.ts` 契约未变。
- 同步中英文 README、更新记录、版本号、兼容性表格、徽章、npm 渠道说明与升级示例。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.16
```

<h3 id="en-v0416">DSH Notify 0.4.16</h3>

Tracks DSH `0.2.2-rc.5` without changing notifications, sounds or interactions.

Compatible with DeepSeek Harness `0.2.2-rc.5`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### ⚠️ Changes

- Declares `0.2.2-rc.5` compatible while preserving every previously verified release. This is the first RC published on the npm `latest` channel.
- Read the new `docs/upgrade-guide/v0.2.2-rc.4` section — the only break list covering `rc.4` → `rc.5`. Its single item is a search-provider default: the shipped base composition no longer pins `web.searchProvider`, so `dsh-web` picks one per model route. This plugin performs no web search and reads no search setting.
- Byte-compared the 15 packages this plugin binds across `rc.4` → `rc.5`. Six interface owners are byte-identical apart from their own version: `dsh-client-ui-slots` (the whole `slots` service), `dsh-host-webserver` (`register(route)`), `dsh-jobs`, `dsh-client-ui-renderer`, `dsh-client-ui-session` and `dsh-client-connection`. The four changed files are either that same search work or release metadata: `dsh-base`'s `cordis.patch.yml` drops the fixed `searchProvider`, `dsh-api-remotes`' client differs by one character (`line:152` → `line:174`), `dsh-client-ui-settings-general`'s client substitutes the displayed host version, and `dsh-client-modules`' host half changes the reported commit (`70005a5` → `3f85d88`). Both seats' `.d.ts` contracts are unchanged.
- Synchronizes both READMEs, the changelog, version numbers, the compatibility matrix, the badge, the npm channel note and the upgrade examples.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.16
```
