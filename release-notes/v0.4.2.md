修复「走了审批的任务不再通知完成」，并兼容当前最新的 DeepSeek Harness `0.2.1-alpha.1`。

<h3 id="cn-v042">🐛 修复</h3>

- 走了审批或计划审批的任务，完成时会重新弹出「任务完成」通知；自 `0.3.2` 起这类通知被永久吞掉。
- 门禁现在只在「人还没回答」时压住通知：审批被决定、被门禁的工具返回结果，压住即解除。
- 普通提问（`ask_user_question`）行为不变，它仍可能作为任务的最后一步发出完成通知。

<h3 id="cn-v042">🔌 兼容性</h3>

- 兼容 DeepSeek Harness `0.2.1-alpha.1`（同时声明 `0.2.0-rc.2`）；`>=0.1.7-rc.1 <0.3.0` 本来就接纳两者，范围无需放宽。
- `0.2.1-alpha.1` 不需要代码改动：插件绑定的包只有版本号变化与 `invariant` 模块删除；`ui-layout` 新增的 `shell.bottom` 座位与本插件无关。

<h3 id="cn-v042">✅ 验证</h3>

- 真实会话回放（3830 个可通知回合，其中 81 个含审批）：修复前发出 **8/81** 条，修复后 **81/81** 条，且记录总数不增——不引入重复卡片。
- `0.2.1-alpha.1` 隔离环境实机启动（不触碰使用者 profile）：无兼容性拒载，四条宿主路由与客户端 bundle 全部正常。
- `npm run verify`：静态检查、**110/110** 测试、构建、打包前置检查。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.2
```

宿主半边需重启 `dsh web` 才生效；客户端半边刷新页面即生效。

<h3 id="en-v042">🐛 Fixed</h3>

- A task that asked for an approval or a plan review announces its completion again; since `0.3.2` those notifications were withheld forever.
- A gate now withholds a notification only while the human still owes an answer: a decided approval, or the gated tool returning its result, releases it.
- An ordinary `ask_user_question` is unchanged: it may still be the last operation of a task and announce completion.

<h3 id="en-v042">🔌 Compatibility</h3>

- Compatible with DeepSeek Harness `0.2.1-alpha.1` (and declares `0.2.0-rc.2`); the existing `>=0.1.7-rc.1 <0.3.0` requirement already admitted both, so no range widening was needed.
- `0.2.1-alpha.1` needs no code change: the packages this plugin binds differ only by version bumps and the removal of the `invariant` modules, and the new `shell.bottom` seat `ui-layout` added is not one it uses.

<h3 id="en-v042">✅ Verification</h3>

- Real session replay (3830 notifiable turns, 81 of them gated): **8/81** announced before, **81/81** after, with the same total record count — no duplicate cards.
- Real-machine boot on `0.2.1-alpha.1` in an isolated `DSH_HOME` (the operator's profile is never touched): no compatibility refusal, and every host route and the client bundle answered normally.
- `npm run verify`: static source checks, **110/110** tests, build, and package precondition checks.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.2
```

The Host half needs a `dsh web` restart; the client half takes effect on a page refresh.
