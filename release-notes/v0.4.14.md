<h3 id="cn-v0414">DSH Notify 0.4.14</h3>

跟进 DSH `0.2.2-rc.3`，通知、提示音与交互行为保持不变。

兼容 DeepSeek Harness `0.2.2-rc.3`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### ⚠️ 调整

- 补充 `0.2.2-rc.3` 的兼容性声明，保留此前每一个已实测版本。
- 逐条核对安装包内 `docs/upgrade-guide/v0.2.2-rc.1` 的全部 19 项——这是唯一覆盖 `rc.1` → `rc.3` 的破坏性变更清单（`rc.2`、`rc.3` 都没有新清单）。其中 18 项属于本插件从未使用的接口；唯一沾边的是 `window-drag-regions`：本插件的浮层是固定层、不在任何 `data-window-drag` 行内，而且位于头部下方，宿主全局的 `-webkit-app-region: initial` 已经让它的按钮与链接不可拖动窗口，因此不需要加排除标记。
- 对插件绑定的 15 个包做了 `rc.1` → `rc.3` 的逐字节比对：`dsh-host-webserver` 的 `lib/index.js`（承载 `register(route)` 契约）逐字节相同；`dsh-client-ui-slots`（承载整个 `slots` 服务）只新增一个 `hoc` 槽类型，single/keyed/list/chain 的注册、排序与遮蔽逻辑未变；`dsh-jobs` 只新增 `JobError` 与错误码；`dsh-client-modules` 宿主半边只改了上报的提交号。
- 同步中英文 README、更新记录、版本号、兼容性表格、徽章、npm 渠道说明与升级示例。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.14
```

<h3 id="en-v0414">DSH Notify 0.4.14</h3>

Tracks DSH `0.2.2-rc.3` without changing notifications, sounds or interactions.

Compatible with DeepSeek Harness `0.2.2-rc.3`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### ⚠️ Changes

- Declares `0.2.2-rc.3` compatible while preserving every previously verified release.
- Read all 19 items of the installed `docs/upgrade-guide/v0.2.2-rc.1` section — the only break list covering `rc.1` → `rc.3` (`rc.2` and `rc.3` ship none). Eighteen name surfaces this plugin never uses. The one that touches custom Client overlays, `window-drag-regions`, does not apply: this overlay is a fixed layer outside any `data-window-drag` row and below the header, so the shell's global `-webkit-app-region: initial` already keeps its controls from dragging the window.
- Byte-compared the 15 packages this plugin binds across `rc.1` → `rc.3`: `dsh-host-webserver`'s `lib/index.js` (which owns `register(route)`) is byte-identical; `dsh-client-ui-slots` adds only an additive `hoc` kind, leaving single/keyed/list/chain untouched; `dsh-jobs` only adds `JobError` and its codes; `dsh-client-modules`' host half changes only the reported commit.
- Synchronizes both READMEs, the changelog, version numbers, the compatibility matrix, the badge, the npm channel note and the upgrade examples.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.14
```
