<h3 id="cn-v051">DSH Notify 0.5.1</h3>

修复通知浮层偶尔盖住上方会话工具栏的问题。

兼容 DeepSeek Harness `0.2.3-alpha.2`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### 🔧 修复

- **浮层不再压住聊天区上方的会话工具栏。** 它的垂直起点此前仍写死为 `56px`，当窗口头部比这更高、或页面缩放不是 100% 时，卡片就会落在「轨迹 / 上下文 / 费用 / 统计」那一行上。现在 `toastTopAnchor` 量取会话正文（`[data-conversation-content]`，退化时用 `[data-conversation-scroll]`）的上沿，再下移 8px 起步；`56px` 作为没有该钩子时的下限保留。因为是实测值，窗口高度变化、侧栏收起与页面缩放都会通过原有的同一个观察器跟着走。
- 「屏幕右上」仍使用宿主相关的 `--dsh-toast-top-offset` 变量定位，所以它代表的仍是屏幕顶部，而不是聊天区顶部。

### 验证

- 静态检查、**123 个自动化测试**、构建与包检查通过，打出的 tarball 与检出逐字节一致。
- 新增覆盖：正文上沿 120px → 起点 128px；矮布局与无钩子时保留 56px 下限；正文缺失时回退到滚动体；DOM 测试对真实渲染出的浮层断言正文上沿 128px 时 `style.top === '136px'`。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.5.1
```

<h3 id="en-v051">DSH Notify 0.5.1</h3>

Fixes the notification window occasionally covering the session toolbar above the chat.

Compatible with DeepSeek Harness `0.2.3-alpha.2`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### 🔧 Fixed

- **The window no longer sits on the session toolbar.** Its vertical start was still a hardcoded `56px`, so in a window whose header is taller — or at a page zoom other than 100% — the card landed on the 轨迹 / 上下文 / 费用 / 统计 row. `toastTopAnchor` now measures the conversation body (`[data-conversation-content]`, falling back to `[data-conversation-scroll]`) and starts 8px below its top edge, keeping `56px` as the floor for a host without the hook. Because it is measured, a resized header, a collapsed sidebar and a zoom change all follow through the same observer that already re-anchored the horizontal gutter.
- The screen-corner placement keeps its host-aware `--dsh-toast-top-offset` variable, so 屏幕右上 still means the top of the screen rather than the top of the chat.

### Verified

- Static checks, **123 automated tests**, build and package checks pass, and the packed tarball matches this checkout byte for byte.
- New coverage: a body top of 120px yields a 128px start; the 56px floor holds for a short layout and for a host without the hook; the scroll body stands in when the content wrapper is absent; and the DOM test asserts `style.top === '136px'` on the rendered frame for a body top of 128px.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.5.1
```
