<h3 id="cn-v0415">DSH Notify 0.4.15</h3>

跟进 DSH `0.2.2-rc.4`，通知、提示音与交互行为保持不变。

兼容 DeepSeek Harness `0.2.2-rc.4`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### ⚠️ 调整

- 补充 `0.2.2-rc.4` 的兼容性声明，保留此前每一个已实测版本。
- 读取新增的 `docs/upgrade-guide/v0.2.2-rc.3`——唯一覆盖 `rc.3` → `rc.4` 的破坏性变更清单。它只有一项：DeepSeek 流式内容拒答的错误码从 `MALFORMED_RESPONSE` 改为 `CONTENT_REFUSED`。本插件不按 LLM 错误码分类：唯一读取的错误码是卡片内回答链路上的 `ASK_ABORTED`，失败回合只按消息文本播报，所以无论宿主报哪个错误码，拒答照旧生成同一张错误卡。
- 对插件绑定的 15 个包做了 `rc.3` → `rc.4` 的逐字节比对：除各包 `package.json` 的版本号外全部逐字节相同，运行时只有两个文件变动——`dsh-client-ui-settings-general` 的客户端只替换了界面显示的宿主版本号，`dsh-client-modules` 宿主半边只改了上报的提交号（`6b729fe` → `70005a5`）。承载整个 `slots` 服务的 `dsh-client-ui-slots`、承载 `register(route)` 的 `dsh-host-webserver`、以及 `dsh-jobs`、`dsh-client-ui-renderer`、`dsh-client-ui-session`、`dsh-client-connection` 全部逐字节相同，两个挂载点的 `.d.ts` 契约也未变。
- 同步中英文 README、更新记录、版本号、兼容性表格、徽章、npm 渠道说明与升级示例。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.15
```

<h3 id="en-v0415">DSH Notify 0.4.15</h3>

Tracks DSH `0.2.2-rc.4` without changing notifications, sounds or interactions.

Compatible with DeepSeek Harness `0.2.2-rc.4`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### ⚠️ Changes

- Declares `0.2.2-rc.4` compatible while preserving every previously verified release.
- Read the new `docs/upgrade-guide/v0.2.2-rc.3` section — the only break list covering `rc.3` → `rc.4`. Its single item moves the DeepSeek streamed-content refusal code from `MALFORMED_RESPONSE` to `CONTENT_REFUSED`. This plugin classifies no LLM error code: the one code it reads is `ASK_ABORTED` on the in-toast answer path, and a failed turn is announced from its message text, so a refusal still produces the same error card under either code.
- Byte-compared the 15 packages this plugin binds across `rc.3` → `rc.4`: apart from each package's own version, everything is byte-identical, with exactly two runtime files touched — `dsh-client-ui-settings-general`'s client substitutes the host version string it displays, and `dsh-client-modules`' host half changes the reported commit (`6b729fe` → `70005a5`). `dsh-client-ui-slots` (the whole `slots` service), `dsh-host-webserver` (`register(route)`), `dsh-jobs`, `dsh-client-ui-renderer`, `dsh-client-ui-session` and `dsh-client-connection` are byte-identical, and both seats' `.d.ts` contracts are unchanged.
- Synchronizes both READMEs, the changelog, version numbers, the compatibility matrix, the badge, the npm channel note and the upgrade examples.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.15
```
