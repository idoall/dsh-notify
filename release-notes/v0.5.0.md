<h3 id="cn-v050">DSH Notify 0.5.0</h3>

通知浮层默认改到**会话区左上角**，其余位置作为备选。

兼容 DeepSeek Harness `0.2.3-alpha.2`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### ✨ 新增

- **默认位置改为会话区左上角。** 全新配置拿到 `toastPosition: 'conversation-left'`；设置页把它列在第一位标为「会话区左上（默认）」，并保留「会话区右上」「屏幕右上」「关闭页面通知」作为备选——你此前选过的位置不会被改动。
- 左侧定位新增 `toastLeftAnchor`：量取会话区左边缘（本身已在左侧栏右侧）再加同样的 16px 留白；拿不到 DSH 钩子时退回居中的内容宽度估算。
- `toastInsets` 统一决定贴哪一边：左上固定 inline start 并清空 inline end，其余位置仍贴右边；手机窄屏维持原来的满宽留白。
- 一次测量（`toastAnchors`）同时给出两侧锚点，复用已有的跟随观察器（ResizeObserver + MutationObserver + transitionend + 约 450ms 的 rAF），所以左侧位置和右侧一样会跟着侧栏展开/收起实时重定位。

### ⚠️ 调整

- `TOAST_POSITIONS` 成为宿主唯一的合法取值来源：存档或 config POST 里的未知位置仍会被丢弃，不会被采纳。
- 包描述与中英文 README 同步新默认；设置页的说明文字与选项标签都直接标出哪个是默认值。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.5.0
```

<h3 id="en-v050">DSH Notify 0.5.0</h3>

The notification window now defaults to the **conversation's top-left corner**; the other positions stay as alternatives.

Compatible with DeepSeek Harness `0.2.3-alpha.2`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### ✨ Added

- **The default position is now the conversation top-left.** A fresh profile gets `toastPosition: 'conversation-left'`; the settings page lists it first as 会话区左上（默认） and keeps 会话区右上, 屏幕右上 and 关闭页面通知 as alternatives, so a position you already chose is never rewritten.
- A new `toastLeftAnchor` measures the conversation column's left edge plus the same 16px gutter, falling back to the centred-content guess when the DSH hook is absent.
- `toastInsets` owns the edge decision: the left placement pins the inline start and clears the inline end, the others stay right-pinned, and a phone keeps the full-width gutter it always had.
- One measurement (`toastAnchors`) serves both sides, so the existing sidebar-following observer re-anchors the left placement exactly as it re-anchored the right one.

### ⚠️ Changed

- `TOAST_POSITIONS` is the single list the Host validates against, so an unknown position in a stored file or a config POST is still dropped rather than adopted.
- The package description and both READMEs describe the new default, and the settings hint names it.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.5.0
```
