<h3 id="cn-v030">通知展示与设置体验更新</h3>

### 新增

- **增强版 / 柔和版**：通知样式可保存。默认增强版提供清晰状态色和短暂提醒条；提醒条结束后通知继续保留。
- **预览与自测**：可单独发送完成、确认、失败、信息示例；可重播四种状态、折叠当前示例或清空。所有测试只存在于当前页面，不会发送系统通知或影响真实任务。
- **市场截图清单**：新增 `screenshots.json`，明确声明当前产品截图的顺序。

### 改进

- 多条通知默认折叠：最新卡片完整显示在顶层，早期完整卡片在下方按 `18px` 等距露边；移入或键盘聚焦后展开。
- 重做“设置 → 通知”，按通知显示、提示音、任务提醒和预览与自测分区；桌面端自测按钮紧凑排列，窄屏自动重排。
- 点击通知跳转会话后，左侧导航会自动显示已选会话，跨工作区也无需手动寻找。
- 双语 README 与截图已同步为当前界面与行为。

### 修复

- 增强版自测通知会使用对应的真实状态色，而不是默认灰色。

<h3 id="en-v030">Notification presentation and settings refresh</h3>

### Added

- **Enhanced and Soft styles**: persisted notification presentation choices. Enhanced is the default, with clear status colour and a short attention bar that never dismisses a notification.
- **Preview and self-test**: send local Completed, Confirm, Failed, and Info examples; replay all four, fold active examples, or clear them. Tests stay in the current page and never affect system notifications or real tasks.
- **Storefront screenshot manifest**: `screenshots.json` explicitly declares the current product screenshot order.

### Improved

- Multiple notifications collapse by default: the newest card remains fully visible while older complete cards expose equal `18px` lower edges. Pointer entry or keyboard focus expands the stack.
- Redesigned **Settings → Notifications** around display, sound, task reminders, and preview controls. Desktop test buttons are compact; narrow screens reflow them.
- Opening a session from a notification now reveals its selected row in the left navigation, including across off-screen workspaces.
- Both READMEs and screenshots now match the current UI and behavior.

### Fixed

- Enhanced self-test notifications use their actual status tone instead of neutral gray.
