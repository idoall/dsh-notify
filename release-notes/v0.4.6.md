声明兼容 DeepSeek Harness `0.2.1-alpha.5`，代码零改动；顺带修正中文 README 里落后了两个版本的 DSH 徽章。

<h3 id="cn-v046">🔌 兼容性</h3>

- 兼容 DeepSeek Harness `0.2.1-alpha.5`：`dsh.compatibility.dshReleases` 增加这一行；`>=0.1.7-rc.1 <0.3.0` 本来就接纳它，范围无需放宽，也不需要版本豁免。
- `0.2.1-alpha.5` 不需要代码改动：插件绑定的十几个包在这一版之间逐字节相同；仅有的两个改动都不在本插件路径上——`dsh-tools` 只改了 `run_code` 工具的描述文案（不涉及 `toolCallId`、`isError` 或本插件读取的 `tool/result` 会话事件），`dsh-client-ui-settings-general` 只替换了界面显示的宿主版本号。

<h3 id="cn-v046">🐛 修复</h3>

- 中文 README 的 DSH 徽章此前停在 `0.2.1-alpha.3`，落后两个版本：英文徽章、环境要求、兼容性标题与版本表都已更新，只有它没跟上，而徽章恰恰是读者第一眼看到的东西。现已与其他声明一致。
- 本版发版时对中英文 README 做了整体版本号审计，而不只是改动正在编辑的那几行。

<h3 id="cn-v046">✅ 验证</h3>

- 真实运行的 `0.2.1-alpha.5` 上，加载器只拒了 `browser-use` 与 `browser-use-playwright-mcp` 两行，本插件未被拒载，也没有动用任何版本豁免。
- 宿主半边实测：`/health` 报 `guiAvailable: true`、`eventErrors: 0`；`/config`、`/sounds`、`/update` 均返回 200。
- 客户端半边实测：页面客户端插件包内含 `@idoall/dsh-notify/client.js`，实际下发的合并包 200（4.4 MB），带 `settings.section` 与 `shell.overlay` 注册。
- `npm run verify`：静态检查、**110/110** 测试、构建、打包前置检查。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.6
```

本版只有兼容性声明与文档修正，在 `0.2.1-alpha.5` 上运行的 `0.4.5` 功能上无需升级；这条命令只是把 npm 上的版本与声明同步到最新。

<h3 id="en-v046">🔌 Compatibility</h3>

- Compatible with DeepSeek Harness `0.2.1-alpha.5`: `dsh.compatibility.dshReleases` gains that line; the existing `>=0.1.7-rc.1 <0.3.0` requirement already admitted it, so no range widening and no exemption were needed.
- `0.2.1-alpha.5` needs no code change: the packages this plugin binds are byte-identical across the release, and the only two that changed are off its paths — `dsh-tools` rewrote the `run_code` tool's descriptions (never `toolCallId`, `isError` or the `tool/result` session event this plugin reads), and `dsh-client-ui-settings-general` only substituted the displayed host version string.

<h3 id="en-v046">🐛 Fixed</h3>

- The Chinese README's DSH badge still said `0.2.1-alpha.3`, two releases behind. The English badge, the Requirements line, the Compatibility heading and the release table had all moved on; only the badge a reader sees first was left behind. It now matches every other declaration.
- This release audited both READMEs for stale version strings as a whole, rather than trusting the lines being edited.

<h3 id="en-v046">✅ Verification</h3>

- Client half measured live: the page lists `@idoall/dsh-notify/client.js` in its plugin bundle, and the served combo bundle answered 200 (4.4 MB) with the `settings.section` and `shell.overlay` registrations.
- `npm run verify`: static source checks, **110/110** tests, build, and package precondition checks.

### Upgrade

