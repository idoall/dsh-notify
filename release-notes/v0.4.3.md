修正设置页两个下拉框的字号，其余不变；兼容 DeepSeek Harness `0.2.1-alpha.1`。

<h3 id="cn-v043">🎨 优化</h3>

- 「通知位置」与「提示音」两个下拉框的字号固定为 13px，与同一张卡片的标签一致。
- 此前它们是这一区里唯一没有固定字号的控件，会跟随宿主的正文字号（默认 14px，可调到 22px），因此看起来比自己的标签还大。

<h3 id="cn-v043">✅ 验证</h3>

- 静态检查新增一条守卫：`.dsh-notify-select` 必须自己声明字号，防止再次退回「跟随宿主字号缩放」。
- 反证：去掉该声明后 `npm run typecheck` 即以 `the settings select must pin its own font-size…` 失败，恢复后通过。
- `npm run verify`：静态检查、**110/110** 测试、构建、打包前置检查。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.3
```

客户端半边刷新页面即生效（服务端半边本次无改动）。

<h3 id="en-v043">🎨 Improvements</h3>

- The 「通知位置」and「提示音」dropdowns now state a fixed 13px, matching the labels in their own card.
- They were the only controls in the section without a fixed size, so they followed the host's content font size (14px by default, user-settable to 22px) and looked larger than the labels beside them.

<h3 id="en-v043">✅ Verification</h3>

- A static guard now requires `.dsh-notify-select` to declare its own font size, so the control cannot silently go back to scaling with the host's content font size.
- Counter-proof: removing the declaration fails `npm run typecheck` with `the settings select must pin its own font-size…`; restoring it passes.
- `npm run verify`: static source checks, **110/110** tests, build, and package precondition checks.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.3
```

The client half takes effect on a page refresh; the Host half is unchanged in this release.
