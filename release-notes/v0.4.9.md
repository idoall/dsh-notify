<h3 id="cn-v049">DSH Notify 0.4.9</h3>

通知太多时，一次收走，而不是逐条点 ×。

兼容 DeepSeek Harness `0.2.1-rc.3`；宿主版本范围仍为 `>=0.1.7-rc.1 <0.3.0`。

### ✨ 新增

- **通知堆叠「全部清除」**：有两条及以上通知时，右上角堆叠上方会出现一个「全部清除」清除条，一次收走本页所有卡片。
- 清除只发生在本页：不替你回答或审批，会话里等待的交互仍在；已清除的通知不会被后续轮询重新弹出。
- 清除条独立成行（20px 胶囊 + 6px 间距），不压卡片内容；折叠或展开时都在，队列计数 `+N` 随之下移，两者不会重叠；只有一条通知时不出现。

### ✅ 验证

- 新增 3 个 DOM 测试：单条通知不显示清除条；一次清空后轮询不会复活；清空待处理问题不等于替用户回答。全套静态检查、**112 个自动化测试**、构建与打包检查通过。
- 在真实 DSH `0.2.1-rc.3` profile 中预览构建产物，确认设置页、通知堆叠与清除条正常；本版不改变 DSH 兼容声明、宿主版本范围或既有通知行为。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.9
```

<h3 id="en-v049">DSH Notify 0.4.9</h3>

Too many notifications? Clear the whole pile instead of clicking × one card at a time.

Compatible with DeepSeek Harness `0.2.1-rc.3`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### ✨ Added

- **Clear all above the notification pile.** With two or more cards, a 全部清除 strip sits above the pile and retires every card on the page at once.
- Clearing stays page-local: nothing is acknowledged, a pending question or approval still waits in its session, and cleared records are not presented again by later polls.
- The strip is part of the frame's height (a 20px pill plus a 6px gap) instead of covering card content, and the `+N` queue counter moves down so the two never overlap. A single card shows no strip.

### ✅ Verified

- Three new DOM tests: a single card offers no strip, one click clears the pile without the next poll resurrecting it, and clearing a pending question is not an answer. Full static checks, **112 automated tests**, build, and package checks pass.
- Previewed in a real DSH `0.2.1-rc.3` profile with the built client bundle; the settings section, the toast stack, and the clear-all strip were confirmed in the running page. DSH compatibility declarations, the host requirement, and notification behavior are unchanged.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.9
```
