<h3 id="cn-v0.2.3">首个由 CI 发布的版本</h3>

从 0.2.3 起，发版不再需要本机手动 `npm publish`：推 `v*` 标签后由 GitHub Actions 跑测试、打包，再通过 OIDC 直接发布到 npm，并自动附上 **provenance** 溯源证明（0.2.2 是手动发布的，没有这份证明）。

### 其他

- **`assets/` 不再随 npm 包发布**：npm 页面上的 README 图片是 npm 把相对路径改写成 GitHub raw 地址（`https://raw.githubusercontent.com/idoall/dsh-notify/HEAD/assets/*.png`）后加载的，所以四张截图照常显示，而每次安装少下载约 176 KB（包从 227 KB 回到约 53 KB）。`npm run pack:check` 改为校验「README 里引用的每张相对图片都确实存在于仓库中」。
- CI 的 `actions/checkout`、`actions/setup-node` 升到 v7，消掉 GitHub Actions 里的 Node 20 弃用提示。
- **插件行为没有任何变化**；内部身份仍是 `dsh-notify`，`/plugins/dsh-notify/*` 路由与 profile 配置不受影响。

<h3 id="en-v0.2.3">First CI-published release</h3>

From 0.2.3 on, a release no longer needs a manual `npm publish`: pushing a `v*` tag makes GitHub Actions test, pack and publish to npm through OIDC, which also attaches the package's **provenance** attestation (0.2.2 was published by hand and carries none).

### Chores

- **`assets/` no longer ships inside the npm tarball**: the README images on the npm page are loaded from GitHub raw URLs (`https://raw.githubusercontent.com/idoall/dsh-notify/HEAD/assets/*.png`), so the four screenshots keep working while every install drops ~176 KB (227 KB back to about 53 KB). `npm run pack:check` now verifies that every relative README image exists in the repository instead.
- CI moves to `actions/checkout@v7` and `actions/setup-node@v7`, clearing GitHub's Node 20 deprecation notice.
- No plugin behaviour changes; the internal identity stays `dsh-notify`, so the `/plugins/dsh-notify/*` routes and the profile config are unaffected.
