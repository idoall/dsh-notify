<h3 id="cn-v0413">DSH Notify 0.4.13</h3>

跟进 DSH 新版，通知、提示音与交互行为保持不变。

兼容 DeepSeek Harness `0.2.2-rc.1`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### ⚠️ 调整

- 补充当前 DSH RC 的兼容性声明，保留此前已验证版本。
- 同步中英文 README、更新记录、版本号与升级示例。
- 明确当前 DSH 需要 Node.js 24.9.0 或更新版本；插件自身的 Node.js 范围不变。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.4.13
```
