<h3 id="cn-v052">DSH Notify 0.5.2</h3>

修复「通知已经点掉、浏览器标签上的提示却还在」。

兼容 DeepSeek Harness `0.2.3-alpha.2`；宿主范围保持 `>=0.1.7-rc.1 <0.3.0`。

### 🔧 修复

- **处理过的通知现在会同时清掉标签页提示。** 标题里的 🔔 与红色小圆点此前只在「页面重新可见」时才停；如果你是在浏览器仍判定为隐藏的窗口里把卡片关掉（窗口被其他窗口完全遮住、副屏、桌面外壳都会这样），或者在那种窗口里点「全部清除」、在卡片里回答、点卡片跳转，标签就会继续为一个已经处理完的通知闪烁。现在卡片一退场（点 ×、清除、回答、跳转）就立刻从未读集合里移除，滑出动画结束时再兜一次底，并且提示数量按「仍在屏幕上的卡片」重算，任何移除路径都不会留下过期的计数。
- **提示停止时不再回滚宿主改过的标题与图标。** 以前停止会恢复它启动时抓到的那个标题，如果这期间会话被改名，就会把新名字悄悄改回去；现在只撤销它自己画上去的东西。
- **提示器改为用到时才解析 `document`。** 客户端 bundle 在页面装好 `document` 之前求值，或者测试替换全局对象时，以前会拿到一个什么都不做的空提示器。

### 验证

- 静态检查、**125 个自动化测试**、构建与包检查通过，打出的 tarball 与检出逐字节一致。
- 新增覆盖：后台到达的通知会标记标签页；在页面仍被判定为隐藏时关掉卡片，标记随之消失；宿主中途改掉的标题/图标在停止后保持不变；模块求值之后才安装的 `document` 也能生效。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.5.2
```

<h3 id="en-v052">DSH Notify 0.5.2</h3>

Fixes the tab marker outliving a notification the user already handled.

Compatible with DeepSeek Harness `0.2.3-alpha.2`; the host requirement remains `>=0.1.7-rc.1 <0.3.0`.

### 🔧 Fixed

- **Handling a notification now clears the tab marker in the same breath.** The 🔔 title prefix and the red favicon dot only stopped when the page became visible, so closing a card from a window the browser still reports as hidden — an occluded window, a second display, a desktop shell — left the tab flashing about work already done. A retiring card (×, clear-all, answer, jump) now leaves the unread set at the click, the slide-out timer drops it again as a backstop, and the count is recomputed from the cards still on screen so no removal path keeps a stale number.
- **Stopping no longer reverts a title or favicon the host changed meanwhile.** It used to restore whatever title it captured at the start, silently undoing a session rename; now it only undoes what it painted itself.
- **The indicator resolves `document` when it is needed**, instead of capturing it at module load — a Client bundle evaluated before the page installs its document used to get an indicator that did nothing.

### Verified

- Static checks, **125 automated tests**, build and package checks pass, and the packed tarball matches this checkout byte for byte.
- New coverage: a background toast marks the tab, closing it clears the marker while the page still counts as hidden; a host title/favicon change survives the marker; and a document installed after module evaluation is picked up.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-notify@0.5.2
```
